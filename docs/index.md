# Mini Mercado EJC

Bem-vindo à documentação do projeto Mini Mercado EJC.

Esta documentação cobre o backend, o frontend, o banco de dados e a API do sistema.

## Navegação

- **Backend** — arquitetura, rotas e validação do servidor.
- **Database** — esquema Prisma e relacionamentos.
- **Frontend** — estrutura da aplicação React e fluxo de autenticação.
- **API** — endpoints disponíveis e exemplos de uso.

## Como usar

1. Instale as dependências do MkDocs:

```bash
pip install mkdocs-material
```

2. Rode o servidor de documentação:

```bash
mkdocs serve
```

3. Acesse em:

```text
http://127.0.0.1:8000
```

## Observações

- A documentação está organizada em `docs/`.
- O arquivo de configuração do MkDocs está em `mkdocs.yml`.
